# Spacio AM — Marketing UI Kit

A single-page editorial marketing site for the Spacio AM brand: hero, philosophy, properties, service tiers, brand quote, contact, and footer. Built in React with the tokens from `colors_and_type.css`.

## Files

- `index.html` — full interactive marketing page
- `components.jsx` — `Nav`, `Wordmark`, `Sparkle`, `Display`, `Body`, `Button`, `Brush`, `PropertyCard`, `TierCard`, `Footer`, `Eyebrow`

## Notes

- Uses lifestyle / amenity photos as placeholders — **swap in real property photography when available** (`assets/amenities-bath-*` and `assets/lifestyle-*`).
- Brushstroke motif (`assets/brushstroke.svg`) appears in three sections with varying opacity/flip.
- Peach (`#E9826A`) only appears as: pulse dot in hero stats, accent dot in property cards, focused input border. Never as a fill.
