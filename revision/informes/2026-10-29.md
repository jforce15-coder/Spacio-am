### P-2026-10-29-05 · Páginas nuevas del Hub usan --border como color: el campo de texto se queda sin borde

- Tipo: token · Impacto: bajo · Recomendación: **revertir** · En el DS: distinto
- Apps con el cambio: hub · Afectadas: hub

En el DS --border ya es el borde completo (1px solid #D8D4CE). claude.html y alma/ escriben «1px solid var(--border, …)», que queda «1px solid 1px solid #D8D4CE»: el navegador descarta la regla y el campo pierde el borde (sobre fondo alabastro casi no se ve). Arreglo: border:var(--border) o 1px solid var(--divider).

Evidencia:

- `hub` · `claude.html:27` — input { border: 1px solid var(--border, #E4DFDA); } — la página carga ds/tokens/colors.css
- `hub` · `alma/index.html:31` — textarea { border: 1px solid var(--border, #d6cfc4); }
- `hub` · `alma/instalar.html:22` — solid var(--border, #d6cfc4)
- `ds` · `tokens/colors.css` — --border:1px solid var(--color-warm-grey) · --divider:var(--color-warm-grey)
